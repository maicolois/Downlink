The test serves the real shared HTML/CSS/JavaScript and service worker with a **synthetic API**. Both selected images show the home page, with no account or third-party media. The script also creates fixture result screens; those are not presented as real downloads here.

There were no tracked application screenshots in the checkout at the start of this audit. Existing PNG assets were icons and a background. Historical Android reports refer to ignored `artifacts/emulator/` images that were not available locally; no Android or native iOS screenshot is claimed.

## Reproduce

From the repository root:

```sh
npm ci
node node_modules/playwright-core/cli.js install webkit
npm run test:ios-embedded
```

Install Chrome or set `CHROME_PATH` first. The script writes screenshots under `artifacts/ios-embedded/`, which is ignored by Git. Review the images and copy the selected files into `docs/screenshots/` intentionally. Browser rendering, fonts and animated backgrounds may change the bytes between runs.

A screenshot produced before a later test failure is evidence of appearance, not proof that the entire suite passed. See [the validation record](../VALIDATION.md).
