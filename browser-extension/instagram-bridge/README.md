# Puente de Instagram para Downlink

Esta extensión local permite abrir el inicio de sesión de Instagram en una pestaña del mismo Chrome o Edge. Solo lee las cookies de `instagram.com` al volver a Downlink durante una conexión iniciada —o al pulsar **Comprobar ahora**— y las entrega a la aplicación local mediante un token temporal.

## Instalar en Chrome

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador**.
3. Pulsa **Cargar descomprimida**.
4. Selecciona la carpeta `browser-extension/instagram-bridge` de este proyecto.

## Instalar en Edge

1. Abre `edge://extensions`.
2. Activa **Modo de desarrollador**.
3. Pulsa **Cargar descomprimido**.
4. Selecciona la carpeta `browser-extension/instagram-bridge` de este proyecto.

Después, recarga Downlink. La extensión no lee contraseñas, formularios ni cookies de otros sitios.
